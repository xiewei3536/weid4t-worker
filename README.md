# 偉電視 · 管理中心(Cloudflare Worker)

電視盒 App「偉電視」的**遠端管理中心**。手機瀏覽器開 `/admin` 登入,就能:換直播源 token、發公告與跑馬燈、**啟動碼授權與防盜用**、封鎖 / 傳話、看每台盒子在線與**正在看的頻道**、**遠端協助(重載頻道 / 幫他切台 / 重啟 App)**、**遠端調字體大小**、推 OTA 更新——全部不必碰盒子。

**2.1.0 起會主動盯著**:每 5 分鐘讀直播源伺服器的看門狗狀態與盒子心跳,直播源異常、恢復、重點盒子離線、盒子載入頻道失敗都會**發 Telegram 通知**;總覽一眼看到 綠 / 黃 / 紅 狀態燈與 24 小時健康色條——長輩打電話來之前你已經知道了。

**2.3.0 起有備援線路**:直播源可再填一條**備援訂閱網址**,主線路連續失敗時盒子自動改用(兩份清單同名頻道合併成多線路);兩條線路各自監控、**分級通知**(主線路壞但備援正常 → 較不緊急;兩條都壞 → 緊急)。另有**家用備援**:家裡電腦跑的代理會自動登記,只下發給同一個家的盒子走區網直連,換新電腦重跑安裝指令即可,不用改管理頁。

影片不經過這裡(盒子直連源站),Worker 只同步「設定」與「授權」,流量極小;裝置心跳有寫入節流,**免費額度綽綽有餘**。

## 🚀 一鍵部署(推薦,全程點按)

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/xiewei3536/weid4t-worker)

點按鈕,Cloudflare 會帶你走完:

1. 登入 / 連結你的 **GitHub**(把這個 repo 複製到你帳號)
2. **自動建立 KV 資料庫**(存設定 / 裝置 / 啟動碼,免手動)
3. **跳出來請你輸入管理密碼**(`ADMIN_PASSWORD`)
4. 自動部署,給你一個網址:`https://weid4t-worker.<你的子網域>.workers.dev`

部署完成後:
- **App 端**:電視盒已內建管理中心網址(`/api/config`),通常免設定。
- **管理端**:手機瀏覽器開 `https://<你的網址>/admin`(帳號隨意、密碼 = 你剛設的)。

## 🔑 設定 / 修改管理密碼(ADMIN_PASSWORD)

一鍵部署若沒跳出輸入框、或想改密碼,用 **Cloudflare 後台**(不是 CLI):

1. Cloudflare 後台 → **Workers & Pages** → 點開 `weid4t-worker`
2. 上方 **Settings** → **Variables and Secrets**
3. **+ Add** → Type 選 **Secret** → Name 填 `ADMIN_PASSWORD`、Value 填密碼 → **Deploy**

> 還沒設密碼時開 `/admin`,頁面會**直接畫出上面這幾步**,照著做即可。

## 🔔 警示通知(Telegram,2 分鐘接好)

1. Telegram 搜尋 **@BotFather** → `/newbot` → 取名 → 拿到 **Token**(像 `123456789:AAxxxx…`)。
2. 搜尋你剛建的機器人按 **Start**(機器人不能主動先找你);要發到家人群組就把它加進群組。
3. 搜尋 **@userinfobot** 按 Start 拿 **Chat ID**(群組 ID 是負數)。
4. `/admin` → **警示** → 貼 Token 與 Chat ID → **測試發送** → 手機收到 → 勾「啟用」→ **儲存**。

之後會收到:
- 🔴 **直播源異常**(持續超過門檻,預設 10 分鐘——看門狗自己 5～15 分內多半修好,太短會吵)、🟢 **已恢復(中斷幾分鐘)**、⚠️ **看門狗沒回報**(VPS 可能離線;**整台連不上——逾時 / 連線失敗 / 5xx——也算**,不會再被當成第三方源默不作聲;回 404 的第三方源照舊不通知)。
- 有備援線路時分級:🟡 **主線路異常(較不緊急)**——備援線路正常,盒子會自動改用備援;沒設備援但家用備援在線時也是這則(會註明其他地點的盒子仍受影響);🔴 **主線路與備援線路都異常(緊急)**——只發一則,不會主、備各發一次;🟡 **備援線路異常(不影響觀看)** / 🟢 **備援線路已恢復**。家用代理離線不發 Telegram(總覽看得到)。
- ⚫ **重點盒子離線** / 🟢 回來(只對「設為重點監控」的盒子,離線門檻預設 180 分鐘;長輩會關電視,別設太短)。
- ⚠️ **盒子載入頻道失敗**(每台每小時最多一則)。
- 靜音時段(例如 `23-7`)只記錄不發;所有事件都留在「警示紀錄」。

監控由 Cron Trigger 每 5 分鐘執行(`wrangler.toml` 的 `[triggers]`),沒設 Telegram 也照樣記錄與畫色條。Token 只存在 KV、不會下發給盒子、畫面不回填。

## 🛠 遠端協助長輩(重點功能)

長輩電話來說「電視沒畫面」時,不用跑一趟:

1. `/admin` → **裝置** → 找到那台(可用暱稱如「阿嬤房」搜尋),看「正在看」「來源」「最後上線」判斷狀況。

4. 字太小?**字體** 選「大」或「特大」→ 套用,盒子下一次心跳自動重繪畫面。

## 🔐 啟動碼授權(防止 APK 外流盜用)

開啟後,**沒有有效啟動碼的盒子無法觀看**——拿不到直播源、開 App 只會看到「請輸入啟動碼」畫面。

### 啟用步驟(順序很重要)
1. **授權** 分頁 → 先按 **「🔓 一鍵授權所有現有裝置(永久)」**(否則你目前在用的盒子會被一起鎖在外面)。
2. 勾選 **「啟用啟動碼授權」**,填啟動畫面標題 / 說明文字、啟動碼位數 → **儲存授權設定**。

### 產生與管理
- 產生數量(單次上限 200)、有效天數(0 = 永久,從盒子輸入碼那一刻起算)、備註 → 結果彈窗可一鍵複製。
- 裝置卡可直接「授權(天數)」/「撤銷授權」;撤銷啟動碼會同時停用綁定的盒子。
- 到期:盒子自我檢測(開機 + 每 90 秒)跳續期畫面;伺服器端同步不下發直播源(雙保險)。
- 同一 IP 每 10 分鐘最多 30 次啟動碼嘗試(防暴力猜碼)。

`/admin` → **直播源** → 貼上新網址 → 「測試主線路」→ 「儲存直播源」→(可選)「所有盒子重新載入頻道」立刻生效。

## 🏠 家用備援(家裡電腦當備援線路)

家裡的 Windows 電腦跑一個家用代理(另有安裝指令),它每 5 分鐘向管理中心登記一次「我在區網的哪個位址」。管理中心只把這個區網網址下發給**跟它同一個家**的盒子(公網 IP 相同;IPv6 比對同一個 /64),盒子走區網直連,不經過雲端。**換新電腦執行安裝指令就會自動登記,不用改管理頁。**

- **怎麼下發**:同一個家的盒子在 `/api/config` 拿到 `<lanUrl>/playlist.m3u`。角色「備援」(預設)= 當備援線路;角色「優先」= 同一個家的盒子以家用清單為主、雲端主線路改當備援。其他地點的盒子完全不受影響。
- **什麼時候不下發**:手動填了「備援訂閱網址」且角色是「備援」(手動優先)、代理自報異常(`healthy:false`)、超過 2 小時沒登記。
- **免金鑰登記**:同一個公網 IP 在 24 小時內有**已授權(未封鎖、未到期)**的盒子心跳,就算同一個家,直接收下。授權機制沒開、盒子也沒個別授權過的話,先在「授權」分頁按「一鍵授權所有現有裝置」,或改用金鑰。剛授權的盒子最多約 5 分鐘(下一輪監控)後才算數。
- **金鑰(進階,選用)**:「直播源 → 家用備援 → 進階」可顯示 / 複製 / 重新產生;安裝時帶 `X-Home-Key` 就不看盒子。金鑰只存在 KV、不會下發給盒子;帶錯會回 401 並計入防暴力限速(同 IP 10 分鐘 20 次,跟管理密碼分開計)。
- **同時只登記一台**:另一個家的代理正在用(45 分鐘內有登記、那邊的盒子 15 分鐘內有心跳)時,免金鑰登記回 403;帶金鑰可強制接手,那邊沒動靜後也會自動接手。
- **省額度**:同一 IP 每分鐘最多 6 次(記憶體計數,不寫 KV);內容沒變時 30 分鐘才寫一次 KV;免金鑰判斷用監控整理好的「已授權盒子 IP」清單,不會每次登記都列舉裝置。

```http
POST /api/home-proxy
Content-Type: application/json
X-Home-Key: <選用>

{"lanUrl":"http://192.168.31.100:5050","version":"2.3.0","channels":118,"healthy":true}
```

成功 `200 {"ok":true,"stored":true,"via":"box","role":"backup","publicIp":"…","playlist":"http://192.168.31.100:5050/playlist.m3u","lastSeen":"…"}`;
失敗一律 `{"ok":false,"reason":"…","error":"給人看的說明"}`:`400 bad_body / bad_lan_url`、`401 bad_key / no_key_configured`、`403 no_home_box / other_home_active`、`429 rate_limited(Retry-After 60)/ key_locked(Retry-After 600)`、`503`(KV 暫時故障,Retry-After 60)。`lanUrl` 只收 `http://` + 私有 IPv4(10.x、172.16～31.x、192.168.x)+ 可選 port,網域、公網 IP、https、帶路徑一律 400。

## 📦 OTA 自動更新

1. GitHub 建 **Fine-grained token**:只給 `weid4t-app` 的 **Contents: Read-only**。
2. Cloudflare → `weid4t-worker` → **Settings → Variables and Secrets → + Add → Secret**:Name `GITHUB_TOKEN` → **Deploy**。
3. 系統分頁會顯示最新版、大小、更新說明;可「重新讀取最新 Release」;不想長輩看到更新視窗可關閉「允許盒子提示 App 更新」。

## 📡 API / 路由

| 路由 | 說明 |
|---|---|
| `GET /api/config?id=&v=&m=&fs=&now=&ok=&ch=&as=&ack=&pe=&le=&up=&ln=` | 盒子讀設定;登記裝置與回報(版本、機型、字體、正在看、來源結果、自啟、指令回條、**播放健康:近 10 分鐘重連次數 / 最後錯誤 / 運行分鐘**、**`ln` 目前線路:0 主線路 / 1 備援線路**);回應含授權、字體、時鐘、OTA 開關、待送指令、伺服器時間、**`backupSubscriptionUrl` 備援線路**與 **`homeProxy`(`"backup"` / `"primary"` / `""`:這台拿到的線路裡哪條是家用代理)**。**沒帶 `id`、被封鎖或未授權都不會拿到直播源網址(主、備援都一樣)**;管理員專用欄位(Telegram、家用備援金鑰與角色等)一律不下發 |

| `GET /api/activate?id=&code=` | 啟動碼激活(IP 限速) |
| `GET /api/update` · `GET /dl/latest.apk` | OTA 查詢 / 下載(帶 Content-Length 供進度) |
| `GET /api/time` · `GET /api/health` | 對時備援 / 健康檢查(含 `build` 版本) |
| `GET /asset/qr` | 聯絡 QR 圖 |
| `GET /admin` · `GET /admin/partial?name=` · `GET /admin/export?what=codes\|devices\|config` | 管理頁 / 局部刷新片段(依分頁只讀需要的 KV)/ CSV 與設定 JSON 匯出 |

## 🗄 KV 資料

- `config` — 全域設定(源、`backupSubscriptionUrl` 備援線路、公告、跑馬燈、授權、`fontScale`、`showClock`、`otaEnabled`、警示設定、`homeProxyRole` / `homeProxyKey` 家用備援角色與金鑰…;舊資料缺欄位自動補預設值)
- `dev:<裝置id>` — 盒子自己回報的紀錄(上線 / 版本 / `now` 正在看 / `pe` `le` `up` 播放健康 / `ln` `lnAt` 目前線路與切換時間 / `asReport` 本機自啟);只有心跳會寫,無變化時最多每 10 分鐘寫回一次(換線路:距上次切換超過 10 分鐘立刻寫,否則照 3 分鐘節流);沒授權的新裝置 7 天後自動消失,同一 IP 每小時最多登記 10 台
- `devadm:<裝置id>` — 管理員設的(暱稱 / 封鎖 / 授權 / 到期 / 字體覆蓋 / `cmd` 待送指令 / `lastAck` / `watch` 重點監控 / `autostart`);只有管理員與指令回條會寫 → 心跳不會把管理員剛按的指令蓋掉;開機自啟由管理員設定與盒子本機回報「最後改的贏」。舊版單一紀錄會在下次心跳自動搬家
- `code:<啟動碼>` — 啟動碼(狀態、綁定裝置、天數、到期);撤銷授權會連帶把綁定的碼作廢
- `mon:state` — 監控狀態(主線路 `src` 與備援線路 `bsrc` 兩套狀態機、盒子警示旗標、24 小時歷史、最近 40 則警示、`homeIps` 已授權盒子的公網 IP);無變化時最多每 15 分鐘寫一次;2.2 寫的舊資料沒有 `bsrc` 會自動補上
- `homeproxy` — 家用備援代理的登記紀錄(`lanUrl`、`publicIp`、`version`、`channels`、`healthy`、`lastSeen`、`via` 金鑰 / 盒子擔保、`boxId`);內容沒變時 30 分鐘才寫一次
- `cfghist` — 設定版本歷史(最多 12 份快照,供還原;還原不會換掉目前的家用備援金鑰);`audit` — 操作紀錄(最多 200 筆;網址 token 一律遮罩)
- `rl:act:<ip>` / `rl:adm:<ip>` / `rl:hpkey:<ip>` — 啟動碼 / 管理密碼 / 家用備援金鑰猜錯 限速計數(自動過期)
- `update_cache` / `asset:qr` — OTA 快取(查詢失敗也快取 5 分鐘)/ QR 圖(只收 PNG / JPEG / GIF / WebP 真檔頭)

> KV 免費額度:每日 1000 次寫入、**1000 次 list**、10 萬次讀取。list 很貴,所以總覽 / 裝置分頁 3 分鐘才自動刷新一次、每次只 list 一次;額度用完時畫面會明說「讀取失敗」而不是假裝沒裝置。KV 暫時故障時 `/api/config` 回 503,盒子沿用本機快取,不會被誤判成未授權。

## 📁 檔案

```
src/index.js      路由進入點 + Cron scheduled()
src/lib.js        常數、預設設定、KV 讀寫、回應工具、狀態判定、設定歷史、操作紀錄
src/api.js        /api/* 與 OTA、裝置登記(寫入節流)、啟動碼、家用備援登記
src/admin.js      /admin/* 後端(驗證與限速、CSRF、儲存、測試、裝置、啟動碼、上傳/匯入、系統/還原、警示、匯出)
src/monitor.js    監控與警示(主 / 備援線路 status.json 判定與分級、Telegram、24 小時歷史、可用率)
src/ui.js         管理頁 HTML(整頁 + 局部片段:一眼狀態、色條、警示分頁…)
src/ui_assets.js  管理頁 CSS / 前端 JS(AJAX、toast、局部刷新、篩選、預覽)
test/run.mjs      端到端測試;test/mockkv.mjs 模擬 KV;test/serve.mjs 本機預覽伺服器
wrangler.toml     設定(KV 綁定;Cron Trigger;一鍵部署自動填 id)
```

> 本程式**不含任何 token**,可安全公開。直播源與授權都在部署後於 `/admin` 設定。
